# Logistics-Optimization-for-Delivery-Routes-DHL
## Project Overview

This project focuses on analyzing DHL-style logistics data to identify delivery delays, route inefficiencies, warehouse underutilization, and delivery agent performance gaps.
Using SQL for data analysis, the goal was to generate actionable business insights to improve operational efficiency and SLA compliance.

## Dataset Summary

The analysis was performed on:

1000 Shipments

300 Orders

20 Routes

10 Warehouses

50 Delivery Agents

### Tables Used:

dhl_orders

dhl_shipments

dhl_routes

dhl_warehouses

dhl_delivery_agents

## Project Objectives

Analyze delivery delays and transit time

Identify high-risk routes and source countries

Evaluate warehouse performance and utilization

Rank delivery agents based on on-time performance

Create Advanced KPI reports for logistics optimization

## Key KPIs Built

On-Time Delivery % (~6.8%)

Average Delivery Delay per Route (6.8 hrs – 41 hrs range)

Average Delivery Delay per Source Country

Warehouse Utilization % (3% – 10%)

Top Delay Reasons (Traffic 51%, Weather 31%, Technical 18%)

Orders with extreme delays (>120 hrs) – 52 out of 300

## Key Insights

On-time delivery performance is critically low (~6.8%)

Significant route-level delay variation exists

Traffic is the primary cause of shipment delays

Warehouse capacity is severely underutilized

Agent performance varies widely (0% – 24% on-time)

## Tools & Technologies

SQL (MySQL) – Data cleaning, CTEs, window functions, KPI reporting

PowerPoint – Business presentation

## Business Recommendations

Optimize high-delay routes and source countries

Improve on-time delivery through traffic-aware scheduling

Rebalance shipment loads across warehouses

Implement targeted training for low-performing agents

Establish continuous KPI monitoring
